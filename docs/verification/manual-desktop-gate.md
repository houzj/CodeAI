# CodeAI Windows 人工验收

安装包路径

`E:\CodeAI\dist\desktop\codeai-desktop-win-x64.exe`

## 1. 启动与品牌

1. 安装后启动 CodeAI。
2. 确认窗口标题、开始菜单项、快捷方式和安装包名称均为 `CodeAI`。
3. 确认启动页、连接页、菜单和错误页没有 `OpenCode` 或 `opencode` 用户可见文本。

## 2. Project → Worktree → Session

1. 打开 `E:\CodeAI` 项目。
2. 创建两个会话。
3. 确认左侧显示项目、工作区和会话层级。
4. 切换会话，确认 Run、Composer 和正文跟随当前会话变化。
5. 悬停项目和会话，确认卡片显示目录、工作树数量、更新时间和项目归属。
6. 确认 CodeAI 页面顶部没有横向会话 Tab。

## 3. Run、审批和连续输入

1. 发送一个会执行工具的任务。
2. 确认时间线显示任务、工具步骤、结果和最终状态。
3. 在运行中连续发送两条消息，确认输入框不被禁用，消息按顺序进入当前会话。
4. 触发需要审批的命令，确认审批入口显示在当前 Run 中。
5. 分别验证批准、拒绝和停止，确认状态回到可继续发送。

## 4. Artifact 区域

1. 让任务生成或打开文件。
2. 确认右侧出现文件/预览 Tab，正文和 Composer 不被遮挡。
3. 关闭最后一个 Tab，确认右侧自动隐藏。
4. 再次打开文件，确认右侧恢复。
5. 验证全屏审查后退出，确认会话正文恢复。

## 5. 重启恢复

1. 在有项目、两个会话和一个 Artifact Tab 时退出 CodeAI。
2. 重新启动。
3. 确认当前项目、会话、Run 状态和右侧区域恢复。
4. 确认运行中的任务、审批、错误和取消状态与网页开发模式一致。

网页自动化和 Runtime 探针已完成，安装包启动、重启恢复和最终视觉状态需要在本机完成这次人工门禁。
